
# Student Management Portal

## Project Overview
A proposed web application for managing student information.

## Objectives
- Maintain student records.
- Add, view, update and search student details.
- Plan attendance management.
- Organize development using Agile Scrum.

## Methodology
The project uses Agile Scrum practices, including a Product Backlog, Sprint Planning, Sprint Review and Sprint Retrospective.
